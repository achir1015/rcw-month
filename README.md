月班表管理系統 — 內容總結
核心概念

把系統想成一個「檔案櫃」：分護理師、病房助理兩層抽屜，每層裡按「西元年-月」存放一份份月班表，每份月班表裡是每位員工的員編、姓名、每天的班別代碼。

功能一覽

查詢

輸入民國年＋月份查詢，自動換算西元年（115年→2026年）
全員班表：Excel 風格的凍結窗格，上下左右滑動時員編/姓名/日期標題都固定看得到
點擊姓名 → 展開個人月曆式班表，可切換「每週起始星期」重新排版
手機優化：字體全部放大25%，凍結表頭在窄螢幕也能左右滑動

匯入

PDF 匯入：用文字座標自行「畫」出表格（找日期欄當座標尺、用員編位置切員工區塊、姓名依最近的資料列重新配對），處理過表頭拆行、姓名跨行、日期資料巧合誤判年月等實際遇到的怪異排版問題
Excel 匯入：PDF 若是掃描圖檔會失敗，這時可先用外部 OCR 工具轉成 .xlsx 再匯入，走跟 PDF 共用的預覽/確認流程
匯入規則：同一「類別＋年＋月」若已有資料，會先提示、確認後才整批覆蓋，不會疊加

資料備份

匯出/匯入 XML 備份檔（格式參考你提供的另一套系統），可跨裝置搬家或留存

雲端儲存

儲存層演進：一開始用 Claude 預覽專屬的 window.storage → 發現單檔部署會失敗，改用瀏覽器 localStorage → 最後串接 Firebase Firestore 雲端資料庫，換電腦/瀏覽器資料都同步

登入驗證

加了 Firebase Authentication 登入畫面，未登入無法看到系統內容
Firestore 安全性規則搭配設成「只有登入者能讀寫」
目前狀態

一個能實際運作、資料存雲端、有登入保護、支援手機操作的單檔 HTML 系統，且核心的 PDF 解析邏輯已經用你提供的真實班表反覆驗證過正確性。
